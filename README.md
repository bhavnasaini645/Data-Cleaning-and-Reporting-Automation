# Data Cleaning & Reporting Automation

## Project Overview

This project focuses on cleaning sales data and generating summary reports using Microsoft Excel. It demonstrates how to handle missing values, remove duplicate records, calculate total sales, and create visual reports for better data analysis.

## Objectives

* Identify and handle missing values.
* Remove duplicate records from the dataset.
* Maintain consistent data formats.
* Calculate total sales using Excel formulas.
* Generate summary reports and charts.
* Improve data quality and reporting efficiency.

## Tools & Technologies Used

* Microsoft Excel
* Excel Formulas
* Data Cleaning
* PivotTables
* Charts and Data Visualization
* GitHub

## Dataset Description

The dataset contains sales information with the following columns:

* Order ID
* Product
* Category
* Quantity
* Unit Price
* Order Date
* Region
* Total Sales

## Project Workflow

1. Imported the raw sales dataset into Microsoft Excel.
2. Identified missing values and handled them appropriately.
3. Checked and removed duplicate records.
4. Calculated total sales using the formula Quantity × Unit Price.
5. Created a sales summary report using Excel formulas.
6. Generated a category-wise sales report using a PivotTable.
7. Created charts to visualize sales performance.

## Key Features

* Missing-value handling
* Duplicate detection and removal
* Automated sales calculations
* Summary report generation
* Category-wise sales analysis
* Visual representation of sales data

## Expected Outcome

This project demonstrates practical skills in data preprocessing, data quality management, Excel-based reporting, and data visualization.
